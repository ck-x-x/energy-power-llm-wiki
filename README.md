# Energy & Power LLM Wiki

Public site for an Energy Engineering & Power Technology knowledge base (energy storage, hydrogen, Power-to-Gas, natural gas hydrates), built with [Quartz v4](https://quartz.jzhao.xyz) and deployed to GitHub Pages.

- Site: https://ck-x-x.github.io/energy-power-llm-wiki/
- Teaching deck: https://ck-x-x.github.io/energy-power-llm-wiki/static/energy-transition-storage-hydrogen-ptg-ngh.html

Only the curated notes (`content/`) and the HTML deck are published. Original paper PDFs are not included.
